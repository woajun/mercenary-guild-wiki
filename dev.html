재능

등급과 공격 배율
· 계열마다 없음 / 브론즈 / 실버 / 골드 / 무지개
· 그 계열 무기를 들 때 공격 ×0.85 / ×1.0 / ×1.2 / ×1.45 / ×1.8
· 랭크당 보너스는 재능과 무관
· 무지개를 초반에 쉽게 보면 '더 위가 있나?' 기대 → 무지개가 끝이라는 느낌을 줄지 결정 필요
- A. 무지개는 늦게: 숙련도로는 골드까지, 무지개는 숨은 조건·S랭크로만
- B. 시장에서 태어난 무지개 아주 드물게 (지금 엘프 주력 계열 6%, 인간 1%)
- C. 무지개는 특별 연출 (빛·소리·이름 색)로 최고임을 보여 줌
- D. 무지개 위에 숨은 단계를 진짜로 둠 (기대를 보상)
재능으로 얻는 것
· 든 무기 계열 재능 → 공격 배율 ×0.85 / ×1.0 / ×1.2 / ×1.45 / ×1.8
- 지금 방패는 밀쳐내기 거리·지면 강타 피해만, 성물은 회복량으로 쓰임
· 공격 배율은 그대로 + 상태 이상에도 이점 결정 필요
- 기절·얼림·물질화 시간도 재능 배율 적용 (예: 무지개 ×1.8 → 기절 2초가 3.6초)
- 강한 적 저항은 그대로 곱함 (보스 ×0.3)
- 속성 공격 생기면 화상 피해·둔화 세기·걸릴 확률도 같은 배율
- 방패는 받는 피해 감소도 조금 (예: 무지개 −10%) 추가할지
· 안 든 계열 재능 → 보조 효과 (브론즈부터, 전부 동시)
· 무기 추천: 지금 계열보다 재능 낮은 계열 무기는 권하지 않음
· 시장: 직업 재능이 높을수록 비쌈
· 재능과 무관: 랭크 보너스, 레벨업 능력치, 스킬 습득·성장
· 스킬과 연결할지 → '재능과 스킬' 카드 결정 필요
보조 효과
· 들고 있지 않은 계열 재능의 효과 (브론즈 / 실버 / 골드 / 무지개)
- 검 – 공격력 +1% / +5% / +10% / +15%
- 방패 – 받는 피해 −1% / −5% / −8% / −12%
- 사격 – 치명타 확률 +1%p / +3%p / +5%p / +8%p (기본 5%에 더함, 치명타 피해 ×1.5는 그대로)
- 스태프 – 맞은 적 주변 0.5 / 1 / 1.5 / 2칸에 25% 피해
- 성물 – 초당 회복 0.2% / 0.5% / 1.0% / 1.5%
· 모든 재능 동시 적용, 브론즈 포함
· 그 계열 숙련도 10레벨마다 효과 +10%
· 수치 조정안 결정 필요
- 사격: 치명타 확률 +3%p / +6%p / +10%p / +15%p (지금 값은 기대 피해 +0.5~4%로 가장 약함)
- 성물: 초당 회복 0.1% / 0.3% / 0.6% / 1.0% (무지개 1.5%면 67초에 체력 전부, 보스전 안 죽음)
- 숙련도 보너스 +10%/10레벨 → +5%/10레벨 (Lv.70이면 효과 ×1.7로 너무 커짐)
- 검·방패·스태프는 지금 값 유지
재능 등급 상승
· 성장 기준 = 그 계열 숙련도 레벨 적용 전
- 숙련도 Lv.25 → 실버, Lv.45 → 골드, Lv.70 → 무지개
- 이미 그 등급 이상이면 변화 없음
· 기준을 넘으면 바로 오르지 않고, 다음 보스 처치 순간에 오름 적용 전
· 진행도 표시 없음, 오를 때만 '재능 상승!'
· 승급(F→E, E→D, D→C) 때 계열별 15% 상승 → 삭제 적용 전
· 고정 레벨은 뻔함 → 대안 중 고르기 결정 필요
- A. 용병마다 숨은 기준 레벨이 다름 (예: 실버 Lv.15~35)
- B. 기준 넘은 뒤 보스 처치마다 확률, 실패할수록 확률↑
- 어느 쪽이든 최종 기준(Lv.70 등)에선 반드시 오름
숨은 상승 조건 (추후 고민)
· 숙련도 말고도 특별한 순간에 재능이 오를 수 있게 결정 필요
· 후보
- 체력 10% 이하로 보스전 승리
- 동료가 모두 쓰러지고 혼자 남아 승리
- 자기 랭크보다 높은 의뢰 성공

- 승급전 대상을 그 계열 무기로 처치
· 조건은 화면에 안 알림, 오를 때만 '재능 상승!'
재능 발견 (없음 → 브론즈)
· 재능 없음 계열도 숙련도 Lv.10이면 브론즈 생김 적용 전
· 성장과 같은 방식: 다음 보스 처치 순간에 생김 적용 전
· Lv.10 고정은 뻔함 → 등급 상승과 같은 대안(A·B)으로 맞출지 결정 필요
안전망
· S랭크가 되면 가장 많이 쓴 계열은 무지개 확정, 화면에 표시 없음 적용 전
· 등급 상승의 '최종 기준에선 반드시 오름'과 겹침 → 하나로 합칠지 결정 필요

· 게임 시작 때 받는 첫 용병: 재능 전부 바로 보임
· 시장 후보: 영입 전엔 직업(든 무기 계열) 재능만 보이고 나머지는 ?
· 영입하는 순간 전부 보임
종족별 재능 경향
· 재능 개수 (1개 / 2개 / 3개 / 5개 전부)
- 인간 55 / 35 / 9 / 1%
- 수인족 50 / 38 / 10 / 2%
- 엘프 45 / 40 / 12 / 3%
· 잘 나오는 계열: 뽑힐 확률 3배
- 인간 없음 / 수인족 검·방패 / 엘프 사격·스태프
· 등급 확률 (브론즈 / 실버 / 골드 / 무지개)
- 인간 전 계열: 60 / 33 / 6 / 1%

재능과 스킬
· 지금은 관계 없음: 스킬은 랭크로 배우고, 쓸수록 자람
· 재능은 그 계열 무기의 공격 배율에만 영향
· 연결할지 결정 필요

- 무지개면 그 계열 전용 스킬 하나 더

직업

직업 이름
· 직업 = 지금 든 무기 계열. 재능 등급과 무관
- 근접(검) 검사 / 방패 수호자 / 사격 사수 / 스태프 마법사 / 성물 사제
· 무기를 바꾸면 직업도 바로 바뀜
· 표시: 'E랭크 검사' = 랭크 + 직업
· 시장: 들고 온 무기의 직업과 그 재능만 공개, 가격도 그 재능 기준
· 용병정보 재능 줄에도 직업 이름을 씀 → 재능 = 직업으로 오해 결정 필요
- 재능 줄은 계열 아이콘만 또는 계열 이름(검·방패…)으로 바꿀지
· 계열 이름 '근접'과 '검'이 섞여 쓰임 → 하나로 결정 필요
직업 카드
· E랭크 때 직업 카드 3장 중 선택 적용 전
- 든 무기·재능에 따라 후보가 달라짐
· 고른 직업이 이름을 바꿈 (예: 검사 → 기사·광전사) 결정 필요

용병시장

열림과 후보
· 용병단 첫 E랭크 때 열림
· 후보 3명, 지역 클리어하고 돌아오면 새 얼굴
· 새 얼굴 보기 30G
· 정원 처음 5명, 최대 12명
- 늘리기 300 / 500 / 800 / 1200 / 1700 / 2300 / 3000G
· 정원이 차면 누구와 바꿀지 고름
후보 종류
· 첫 대륙: 숙련도 0~6
· 둘째 대륙부터 신병 34% / 경력자 66%
- 신병: 숙련도 0~5, 강화 없음, 쌈. 영입 후 직접 찍음
- 경력자: 대륙별 숙련도 22~32 / 38~48 / 50~60 / 60~70 / 70~80, 랭크 D~C
- 경력자 성향: 공격 / 체력 / 속도 / 스킬 강화를 미리 찍어 옴
· 무기: 그 대륙에서 열린 무기 중 하나 → 직업이 됨
· 종족: 인간 85% / 수인족 12% / 엘프 3%
- 첫 대륙 표만 있음, 다른 대륙은 무작위 → 대륙별 표 결정 필요
가격
· 신병: 100 + 숙련도 × 20
· 경력자: 100 × 대륙 번호 + (숙련도 − 그 대륙 최소) × 20
· 종족 배율: 일반 ×1 / 희귀 ×1.5 / 초희귀 ×2.5
· 직업 재능 배율: 없음·브론즈 ×1 / 실버 ×1.6 / 골드 ×2.5 / 무지개 ×4
· 숨은 재능은 가격에 안 들어감 → 싸게 산 용병이 대박일 수 있음
